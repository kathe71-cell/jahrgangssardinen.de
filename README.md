# Jahrgangssardinen.de - Premium Vintage Sardine Guide

High-conversion editorial landing page & buying guide for European vintage sardines (Nuri, La Belle-Iloise, Conservas Ortiz).

## 🚀 Features

- **Interactive Vintage Explorer**: Filter sardines by maturation age and flavor profiles with direct affiliate links.
- **Sommelier Tasting Guide**: Pairing recommendations for sourdough, French salted butter, Vinho Verde & Champagne.
- **Vercel SPA Export Ready**: Pre-configured `vercel.json`, `sitemap.xml`, and `robots.txt`.
- **SEO & Structured Data**: Built-in JSON-LD schemas for Google Rich Snippets (FAQPage, Organization, ItemList).

```bash
npm run dev
```
